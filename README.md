# Ex.No.-1.2-Design and Draft the given 2D Sketches in modelling software.

## AIM
 To sketch the given drawing with dimensions using fusion 360 tool.
 
## REQUIREMENTS
 1. Autodesk fusion 360
 2. Windows 10
 3. 16 GB of RAM (integrated graphics recommend 1 GB or more)
 4. 2.5 Mbps or faster download; 500 Kbps or faster upload 
 
 ## PROCEDURE
Open Autodesk Fusion 360 software and create a new design.
Select the XY plane and click on Create Sketch.
Draw the two side plates using the Line, Circle and Arc tools.
<img width="1618" height="95" alt="image" src="https://github.com/user-attachments/assets/69dd997d-bd43-47ab-88d7-aa65c9022f96" />
Draw two circular holes on the upper and lower portions of each side plate.

Create the required curved profiles using the Arc tool.
Draw the central circular component using the Circle tool.
Use the Trim tool to remove unwanted portions of the sketch
