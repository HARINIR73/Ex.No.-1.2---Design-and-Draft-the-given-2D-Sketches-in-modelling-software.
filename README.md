# Ex.No.-1.2-Design and Draft the given 2D Sketches in modelling software.

## AIM
 To sketch the given drawing with dimensions using fusion 360 tool.
 
## REQUIREMENTS
 1. Autodesk fusion 360
 2. Windows 10
 3. 16 GB of RAM (integrated graphics recommend 1 GB or more)
 4. 2.5 Mbps or faster download; 500 Kbps or faster upload 
 
 ## PROCEDURE
1. Create a sketch: Start a new 2D sketch on the XY plane centered at the origin.

2.<img width="292" height="227" alt="Screenshot 2026-11-17 203411" src="https://github.com/user-attachments/assets/b313a558-3186-41d5-9ff1-5a2f1c56f198" />

3. Draw the center ring: Sketch two concentric circles at the origin to form the inner hub ring.

 4. <img width="803" height="210" alt="Screenshot 2026-11-17 213008" src="https://github.com/user-attachments/assets/530cc654-7d10-41d6-90c1-d54a9c9cef09" />

5. Add the inner lugs: Draw a tab extending inward from the inner circle and use a Circular Pattern (6 instances) to create the internal teeth.
 
6.<img width="542" height="137" alt="Screenshot 2026-11-17 213311" src="https://github.com/user-attachments/assets/5fb2014b-1ec7-42ad-a071-b815b08de1d9" />
   
7. Sketch the side wing: On one side of the hub, draw a large kidney-shaped wing profile with rounded lobes at the top and bottom.

8.Draw the circular cutout: Sketch a circle inside the wing profile and add thin rectangular gaps to create a C-shaped slot around a center pin.

9. Add the center split: Draw a thin vertical rectangle down the middle of the hub to separate the left and right halves.
  
10. Mirror the geometry: Use the Mirror tool across the vertical center axis to duplicate the wing and slot onto the opposite side.

11. Trim excess lines: Use the Trim tool to remove overlapping lines so only the final closed profiles remain.

12.Extrude the bodies: Finish the sketch and Extrude all profiles symmetrically to give the part its 3D thickness.

13.<img width="696" height="546" alt="Screenshot 2026-11-17 213450" src="https://github.com/user-attachments/assets/c2de7a6a-1483-46c2-b18a-1a3dbf33e77c" />

14.Apply edge fillets: Use the Fillet tool to slightly round off the sharp outer and inner edges.
